# Contributing

Please keep the repository free of original SOCOM game assets.

Allowed contributions include original source code, reverse-engineering
notes, format documentation, hashes/metadata, synthetic tests, and
conversion/runtime code.

Do not commit:

- disc images
- game executables
- ZAR/ZED archives
- extracted textures/models/audio
- converted proprietary game assets

When documenting a reference file, prefer hashes and structural metadata.
